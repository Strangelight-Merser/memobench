# 提交检查清单与邮件模板

截止：**2026年10月16日24:00北京时间（Asia/Shanghai）**，即10月17日00:00、10月16日16:00 UTC；芝加哥当地10月16日11:00（CDT）。不得按电脑日期猜测。按用户提供期限与归档方案准备，本轮未联网核验赛事变更；收件地址、主题格式、附件大小以最终赛事通知为准。

## 三件材料

- [ ] 源码仓库/代码材料：匿名可访问，固定提交ID/版本；README命令可从干净克隆执行；原始输出与哈希可回溯；第三方许可清楚，自建数据采用已授权的 CC BY 4.0。
- [ ] 作品介绍PDF：由 `docs/作品介绍.md` 的10页结构完成排版；逐页打开检查裁切、字体、公式、空页、页码、链接与占位；未实测项明确标未完成，不伪造数字。
- [ ] 演示视频：按 VIDEO.md 连续录制真实过程，目标3分钟（归档规则允许3–5分钟）；展示实际openKylin、两款真实智能体与证据。如未完成如实说明未满足，不用mock替换。

## 发布前签收

- [ ] 独立 AI 审核及主复核、CC BY 4.0 公开许可已记录；语义裁判校准通过；若缺失，提交材料如实标注且不发布正式排名。
- [ ] 两款智能体版本、会话/隔离证据、实际运行机与模型服务机信息齐全。
- [ ] 结果三区分开，online/replay分开，所有数字能从原始记录复算。
- [ ] `python3 -m unittest discover tests`、离线CLI、check_release日志留存；远端CI另保存run URL、commit、实际日志。
- [ ] `python3 tools/check_release.py --root . --strict` 检查正式发布门禁；阻塞不能被普通离线检查成功覆盖。
- [ ] 受控文件凭据扫描与人工复核完成；未把简单扫描说成全历史审计。
- [ ] 干净克隆、匿名访问、PDF与连续视频人工复核完成；代码、报告、邮件版本一致。
- [ ] 发送前由维护者核对收件人、截止和材料链接；保留发送回执。此任务没有发送邮件授权。
- [ ] 可选deb：仅在核心P0通过后构建；openKylin测试机明确同意安装后做安装/运行/卸载。deb不阻塞PDF与视频。

当前缺口详见 VALIDATION.md；本清单的勾选必须由真实证据支持。
