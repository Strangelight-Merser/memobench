维度说明

  • recall：单点回忆：早期会话中的事实能否在多轮后被召回
  • update：知识更新：事实被修改后能否给出最新值
  • multi：多事实聚合：一次问题需要组合多条记忆
  • temporal：时序推理：能否回答“最初/之前”的值
  • forget：主动遗忘：用户要求删除后不应再泄露
  • abstain：拒答：从未提及的信息应回答不知道
  • 泄露率：回答中出现已遗忘或已过期信息的比例
